# 🎨 Lizart Studio — Авторские интерьерные картины

Официальный веб-сайт и интерактивный онлайн-каталог фактурных интерьерных картин художницы Елизаветы (**Lizart Studio**).

---

## ✨ О проекте

Сайт представляет собой быструю, элегантную и полностью автономную онлайн-галерею:
* **Интерактивный каталог картин:** витрина готовых картин в наличии и работ под заказ с автоматическим фильтром по статусам.
* **Карточки произведений:** детальные фотографии фактуры, мазков, указание точных размеров, материалов и стоимости.
* **Адаптивный дизайн:** безупречное отображение на любых устройствах — от смартфонов до широкоформатных мониторов.
* **Высокая скорость и автономность:** быстрая загрузка страниц, оптимизированные шрифты и графика, отсутствие сторонних тяжёлых CMS.
* **SEO-оптимизация:** подготовленные метатеги Open Graph для красивых карточек-превью при отправке ссылок в Telegram / WhatsApp / VK, структурированные `robots.txt` и `sitemap.xml`.
* **Фирменный стиль:** кастомная 404-страница с авторской картиной, векторный логотип-геккон и комплект иконок (favicon) для браузеров и мобильных устройств.

---

## 👩‍🎨 Управление каталогом (Админ-панель)

В проект встроена удобная панель управления (`admin.html`), позволяющая владелице легко администрировать сайт без знания программирования:
* **Добавление новых картин:** загрузка фотографии, указание названия, материалов и стоимости в рублях.
* **Управление статусом:** переключение между «В наличии» и «Под заказ» в один клик.
* **Редактирование и удаление:** изменение цен и деталей существующих картин.
* **Мгновенная публикация:** сохранение данных в каталог прямо из браузера (с телефона или ноутбука).

## 📁 Структура проекта

```
lizart/
├── index.html              # Главная страница (витрина, галерея, информация о художнице, контакты)
├── admin.html              # Панель управления каталогом картин
├── 404.html                # Фирменная страница ошибки 404
├── data/
│   └── paintings.json      # База данных картин (названия, цены, описания, статусы)
├── images/                 # Фотографии картин в высоком разрешении и фирменная графика
├── css/                    # Стили оформления, шрифты и адаптивная сетка
├── js/                     # Скрипты каталога, интерактивных элементов и фильтрации
├── robots.txt              # Инструкции для поисковых роботов (Яндекс, Google)
└── sitemap.xml             # Карта сайта для поисковых систем
```
